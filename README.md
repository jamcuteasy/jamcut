# Jamcut

**한국어** · 촬영본의 편집 준비를 자동으로 해 주는 윈도우 프로그램입니다. 싱크 · 오디오 정리 · 받아쓰기 · 대본 · 프리미어용 시퀀스까지 PC에서 만들고, 판단이 필요한 곳(시나리오 · 인서트 · 색 검토 · 쇼츠 문장)만 AI에 묻습니다.

**English** · A Windows app that preps YouTube edits from your footage — sync, audio cleanup, transcription, script and a Premiere-ready sequence — and asks AI (Claude or ChatGPT) only for the judgment calls.
