    WHY JAMCUT

    편집자가 만든 편집 도구

    기능 목록에서 출발하지 않았습니다. 촬영본 앞에서 매번 반복하던 일을 하나씩 없애면서 만들었습니다.

    0+년 차 영상 전문가
    • 되돌리기용 _무음컷없음 시퀀스를 항상 함께
    • 원본은 읽기만, 결과는 작업 폴더에
    • 확실하지 않은 클립엔 ‘싱크 미확인’ 마커
    • 자막은 글자를 고칠 수 있는 캡션 트랙으로
    • 클립 끝을 늘리면 앞뒤 장면이 그대로
    01 // MADE BY AN EDITOR

    25년 넘게 영상을 만든 사람이 직접 만들었습니다

    개발자가 상상한 편집이 아니라, 현장에서 실제로 손이 가던 순서 그대로입니다. 무음을 자른 시퀀스 옆에는 항상 자르지 않은 시퀀스가 있고, 촬영 원본은 한 번도 건드리지 않습니다.

    02 // AI WHERE IT COUNTS

    AI는 꼭 필요한 곳에만 씁니다

    싱크, 오디오, 받아쓰기, 시퀀스 생성은 전부 내 PC에서 돌아갑니다. AI에는 대본과 장면 이미지 몇 장만 보냅니다. 조작 하나하나를 AI가 대신 누르는 방식보다 크레딧이 덜 들고, 기다리는 시간도 크게 줄어듭니다.

    03 // SHORTS FROM ANYTHING

    완성된 영상 하나로 쇼츠 여러 편

    이미 편집이 끝난 영상 파일이나 프리미어 편집본(XML)만 있어도 됩니다. 프로젝트 설정 없이 바로 쇼츠 화면으로 가고, 시나리오가 다른 안을 쇼츠_A · B · C로 쌓아 두고 골라서 만듭니다.

      내 API 키

      Anthropic · OpenAI 키로 버튼 한 번에 요청합니다. 키는 저장하지 않고 실행 중에만 씁니다.

      멀티캠 싱크

      카메라 A – E, 오디오 A – E를 소리 파형으로 맞춥니다. 소리가 없는 클립은 촬영 시각으로 추정해 놓고 ‘싱크 미확인’ 마커를 남깁니다.

      색 매칭

      보조 카메라를 카메라 A의 피부톤과 옷 색에 맞춥니다. 밝기가 바뀌는 구간마다 LUT를 따로 만듭니다.

      무음 컷

      무음을 잘라낸 시퀀스와 자르지 않은 시퀀스를 항상 같이 만듭니다. 언제든 되돌릴 수 있습니다.

      드리프트 보정

      긴 촬영에서 녹음기와 카메라 시계가 벌어지면 소리 길이를 보정해 다시 맞춥니다.

      오디오 정리

      노이즈 제거와 음량 평준화. 합쳐진 소리가 -3dB를 넘지 않게 클립 볼륨을 잡습니다.

      받아쓰기

      Whisper large-v3가 내 그래픽카드에서 돕니다. 크레딧이 들지 않습니다.

      프리미어 호환

      XML은 모든 프리미어 버전에서 열립니다. 자막은 글자를 고칠 수 있는 캡션 트랙으로 들어갑니다.

      MP4 바로 받기

      프리미어가 없어도 자막, 색 보정, 소리를 합친 MP4로 받습니다.

      원본 보호

      촬영 원본은 읽기만 합니다. 결과는 전부 작업 폴더에 쌓입니다.

      멈추지 않는 처리

      한 단계가 실패하면 건너뛰고 계속할지 그 자리에서 묻습니다. 끝난 단계는 다시 돌리지 않습니다.
